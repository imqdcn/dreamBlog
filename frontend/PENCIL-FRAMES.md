### 0.3 图层命名

```
Frame
├─ BG/atmosphere
├─ Nav/Sidebar
│   ├─ Nav/Brand
│   ├─ Btn/Primary-Record
│   ├─ Nav/Group-Browse
│   │   └─ Nav/Item/Journal (active)
│   └─ Nav/Footer-Logout
└─ Main
    ├─ Header/Title
    ├─ Header/Meta
    └─ List
        ├─ C/Card/Dream-01
        └─ ...
```

组件化前缀：`C/`（组件）、`Btn/`、`Nav/`、`BG/`、`Txt/`。同名组件在 Pencil 里做成 Component，后续 Frame 只放 Instance。

### 0.4 构建顺序

1. Frame 01 建 `C/Card/Dream`、`C/Tag/Neutral`、`C/Pill/Emotion`、`Btn/Primary`、`Nav/Item`
2. 用这 5 个组件拼 Frame 02 / 04 / 05
3. Frame 03 单独建 `C/Modal`（含 idle / pending 两个 variant）
4. 最后做 Frame 06 组件板，把所有状态铺开核对
